🔗 Official rate check karne ke liye verified sources

Yahan click karke asal government rate dekho, phir Rates Management ke "Bulk add" box se RateDost mein daal do.

  • ⛽ Fuel (Petrol/Diesel): ogra.com.pk — OGRA ki official petroleum notifications
  • 🍚 Food / essential items (weekly Sensitive Price Indicator): pbs.gov.pk/price-statistics — Pakistan Bureau of Statistics
  • 🏗️ Construction / Cement: apni province ke Price Control / District administration ki notification list check karo
  • 🌾 Agriculture (wheat support price wagera): apne province ke Food Department ki official website

Note: ye general reference links hain — is HTML file ke andar koi live data auto-fetch nahi hota, khud jaake number check karke Admin se daalna hoga jab tak backend nahi jud jata.

💰 RateDost se kamai kaise ho sakti hai?

Chaar aam tareeke hain jo is tarah ki rate/price websites use karti hain:

  • Ads (Google AdSense wagera): Apni site par ad network ka account banao, unka code milta hai, wo neeche wale box mein paste kar dena — har page par dikhega. Traffic zyada hoga to kamai zyada.
  • Sponsored listings: Kisi dukaan/business ko apni category mein "Featured" ya highlighted spot bech sakte ho (jaise "Sponsored: XYZ Cement Store").
  • Premium/VIP features: Free users ko basic rates milein, paid users ko extra cheezein milein (jaise SMS/WhatsApp rate alerts, city-wise export, ads-free view).
  • Affiliate links: Jahan log calculator use karke kharidari plan karte hain (jaise cement, gold), wahan kisi online store ka affiliate link laga do — har sale par commission mile.

Sabse pehle aam tor par log Ads se shuru karte hain kyunke setup sabse aasan hai. Iske liye AdSense (ya kisi bhi ad network) par apni site register karo, approval milne ke baad wo tumhein ek chhota sa HTML/JS code denge — wahi neeche paste karo.

Ye code Home page aur Market Rates page par ek dedicated "Sponsored" slot mein show hoga. Jab tak koi code nahi hoga, wahan sirf khaali placeholder dikhega — koi fake ad nahi lagega.
